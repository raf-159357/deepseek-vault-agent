# 0.8.0 — 三个功能选项，随插件打包

> 面向手机端：**iPhone 与安卓**。桌面端可装，但不是重点。

## 新增

- **三个功能选项**，随插件一起打包，不联网下载、不生成额外文件：
  - **学 · 学习拆解**（琥珀）——一个知识点讲透：知识点 / 为什么重要 / 打个比方 / 拆开看 / 过程演示 / 关系图谱 / 自测 / 拓展 / 待确认。自测答案折叠，点开才看。
  - **文 · 文献拆解**（靛蓝）——给一个 DOI 就够：先访问 `doi.org`，付费墙就回退到 PMC / arXiv / 作者主页；方法部分自绘流程图；关键数字标出处；**讨论部分完整保留**；末尾 3 道自测题。
  - **帐 · 手帐打卡**（墨绿）——日期标题 + 一张主图 + 三行短句 + 标签；风景照先写画面再写感受；可选热量估算与训练记录。
- **项目笔记（MOC）绑定**：`学习/学习 MOC.md`、`文献/文献 MOC.md`、`手帐/手帐 MOC.md`。执行时先读 MOC，把内容追加到最匹配的章节，并在末尾补一条 `[[本次笔记]]` 反链；MOC 不存在就先建最小骨架。笔记会一章一章往下长，而不是堆成散篇。
- **跨笔记关系图谱**：画图前先用 `search_notes` 找 3–5 篇相关旧笔记，把它们一起画进 mermaid，边上写 `[[笔记名]]`，在 Obsidian 图谱视图里可直接跳转。
- 设置里新增「功能」选择，记住上次用的那一个。

## 变更

- 介绍口径改为**移动端优先**：主打 iPhone 与安卓，桌面端可用但不是重点。
- 系统提示词在原有硬规则之后追加功能块（基座 + 用户补充），不影响原有的缓存命中逻辑。

## 已知限制（下个版本）

- 功能选项目前在设置里的下拉；输入框上方的**彩色标签**在 0.8.1。
- 文献原图暂只保留图注与链接；`save_image` 下载到附件在 0.9.0。
- 「我的补充」编辑页（四个开关 + 自由文本）在 0.8.1。

BRAT 里加 `raf-159357/deepseek-vault-agent`，或手动把 `main.js`、`manifest.json`、`styles.css` 放进 `.obsidian/plugins/deepseek-vault-agent/`。
