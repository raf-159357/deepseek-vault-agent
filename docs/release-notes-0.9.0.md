# 0.9.0 — 小人会动，也会自己走

## 新增

- **会呼吸**：静止时身体轻轻起伏，不再是一张死图。
- **会走动**：每隔 9 秒自己挪一小段，走向哪边就朝哪边倾，像在走；可以在设置里关掉。
- **被戳会蹦**：点一下先跳起来再进指令。
- **拖着走**：按住能拖到屏幕任意位置，松手时压一下再弹回；位置会记住。
- **不出屏**：拖动的边界改成按屏幕实际尺寸算，以前写死 400×800，平板和横屏会卡住。

## 说明

形象仍然是 `1190fasheqi/dafeiyu-pet` 的立绘（MIT），动画全部用 CSS 做，没有引入 any 动画库，包体积几乎没变。
