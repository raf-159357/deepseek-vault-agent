# 0.8.1 — 悬浮按钮换了，功能随手切

## 新增

- **悬浮按钮换成 DeepSeek 鲸鱼标志**：右下角那个圆圈不再是麦克风，还是可以拖动，位置会记住。
- **指令弹窗里加了功能条**：`学 / 文 / 帐 / 其他` 四个按钮，就在输入框上方，点一下即时切换，不用再进设置。
- **「其他」模式**：没有固定结构，你说了要做什么，它自己判断该写成什么样；判断不清时会在开头说明按什么理解做的。
- **支持上传文件**：除了拍照和相册，现在可以选一个 `.md / .txt / .csv / .json` 文件，内容随这条指令一起发出去，读进上下文后照常写进笔记。

## 变更

- 功能条与设置里的「功能」下拉共用同一个值，改哪边都一样。

## 安装

BRAT 里加 `raf-159357/deepseek-vault-agent`，或手动放 `main.js`、`manifest.json`、`styles.css`。
