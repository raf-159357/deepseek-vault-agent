# 0.9.4 — 「我的补充」可以编辑了

## 新增

- 功能条右侧加了 **✎** 按钮，点开就是当前功能的「我的补充」。
- 里面五个开关：生成关系图谱 / 概念建双链 / 出自我检测题 / 估算热量 / 一律新建文件。
- 一个自由文本框（上限 800 字），写你自己的要求，比如「解剖名词标英文缩写」。
- 保存后立刻生效，下次运行就用新提示词；「清空」一键恢复默认。

## 说明

- 补充内容按功能分别存储（`skillMine["study"]` 这样），和基座分开，**插件升级不会覆盖**。
- 安全与事实类规则（不编造、写操作要确认）不在可改范围内。
- 功能条改成右对齐，和右侧按钮的位置更一致。

## 下一步

功能条竖向排在弹窗右侧还在做，手机上要避开输入区，需要单独调布局。
