# DeepSeek Vault Agent

**说一句话，它去搜、去读链接、把笔记写好。** 一个跑在你自己 DeepSeek Key 上的 Obsidian 语音 AI 助手，电脑能用，**iPhone 也能用**。

[English](README.md) · [反馈问题](https://github.com/raf-159357/deepseek-vault-agent/issues) · MIT

---

## 为什么做这个

现在几乎所有 AI 笔记工具都要求你把笔记搬走：搬进 Notion 的云、搬进聊天窗口里反复粘贴，或者装一套只在电脑上跑得动的东西——本地 CLI、后台 Node 进程、MCP 桥接。

这个插件走反方向。你的库还是硬盘上的一堆 Markdown 文件，插件直接在 Obsidian 内部调 DeepSeek，所以**手机上没有服务器、没有桥接、没有配套 App** 也能跑。整个过程压到一个动作：**敲两下手机背面，说，完事。**

它也不吹模型：DeepSeek Flash 不是 GPT-5，也不是 Claude Opus。它快、听话够用、写笔记这个量级看不出差距，而费用大约是同价位订阅的**十分之一**。这个交换就是它存在的理由。

## 能做什么

**语音 → 笔记，四种落点**

| 落点 | 结果 |
| --- | --- |
| 追加到当前笔记 | 口语整理成书面语，接在文末 |
| 改写当前笔记 | 重排整篇，**保留 frontmatter**，只换正文 |
| 改写选中 | 只动你选中的那一段 |
| 新建笔记 | 自动起标题、建目录、重名加序号 |

**一句话指令 → 直接干活，能联网**

用大白话说就行：

- 「查一下 GLP-1 和房颤的最新研究，总结五条写进 文献/综述.md」
- 「把这篇笔记里三个链接都读了，做张对比表」
- 「建个文件夹 课题/开题，在里面写个提纲」

它有九个工具：搜笔记、列目录、读笔记、联网搜、读网页、写笔记、建文件夹、移动改名、移入回收站（默认关闭）。

**拍照**

两个弹窗里都有「拍照 / 相册」：手机上直接调系统相机，桌面上是选文件。照片先压到 1400 px 再上传，所以「拍下这一页 / 这张处方 / 这块白板，整理成笔记」是一步的事。识图只有 `deepseek-flash` 支持；如果你选的是 `deepseek-v4-pro`，这一次请求会自动改用 Flash 并告诉你。

## 0.6.0 当前状态：已经做出来的 / 还没做的

写清楚，是因为上架说明里夸大其词比写得短更糟。

**现在已经能用的（iPhone、安卓、桌面都一样）**

- 语音 → 笔记，四种落点，落笔前一定先给你预览。
- 弹窗内用 DeepSeek 转写语音（单段 120 秒），也可以只用系统键盘听写。
- 手机上一键进门：应用内悬浮圆钮（点一下进 AI 指令，长按进语音笔记，可拖动）、轻点背面、锁屏小组件、操作按钮、快捷指令自动化。
- 中英双语界面，跟随 Obsidian 的语言设置，也可以在插件设置里单独指定。
- AI 指令模式：搜库、读笔记、列目录、联网搜、读链接，然后新建 / 追加 / 覆盖笔记、建文件夹、移动改名 —— 每个写操作都先排队等你点确认。
- 拍照：系统相机或相册，一条消息最多 4 张，上传前先压尺寸。
- 九个工具，默认 8 步（上限 24），单次最多 24 个写操作，单篇最多 20 万字。
- 步数或 8 分钟到上限后，「继续跑」接着原来的对话往下做，不从头再来。
- 待确认队列会写进磁盘，手机把 App 杀掉也不会丢掉已经准备好的十处改动。
- 提示词按缓存规则组织：系统提示词和工具定义逐字节稳定，正在改的那篇笔记单独占一条消息，一次运行里重复读同一篇不再重复计费。每次回答都告诉你命中率和花了多少。
- 设置页有累计账本：请求次数、全部输入的缓存命中率、花了多少、省了多少，可以清零。
- 改写保留 YAML frontmatter；超过 800 KB 的笔记直接拒绝，不截断。
- 用官方 `eslint-plugin-obsidianmd` 规则集重建：0 errors。

**还没做的**

- **不能后台跑。** Obsidian 关着就什么都不会发生；iOS 也不会按计划唤醒 App。「每天早上 8 点」只能靠 iOS 快捷指令的自动化去打开 URI。
- **不能收邮箱。** Gmail 要 OAuth 和原始 socket，Obsidian 的 WebView 两样都没有。绕法是把邮件转发成笔记（或走邮件转 RSS），再用「读这篇笔记里的链接」。
- **没有流式输出。** 结果是整段返回的，久等就是干等。
- **没有对话记忆。** 窗口不关可以接着说下一句，但每次指令都是独立的，不记得上一轮。
- **没有语义搜索。** 只有文件名 + 正文关键词，没有向量检索。
- **不能给每个工具单独写提示词。** 一个系统提示词 + 一个「额外写作要求」输入框。

| **DeepSeek Vault Agent（本插件）** | 你的库，纯 Markdown | 能，且写入前排队确认 | 能，语音优先 | **只付 DeepSeek 用量，重度用约 $2/月** |

### 真正不一样的地方

不装这个第一：社区清单里提到 agent 的插件已经有 260 多个，其中好几个能正经写库。但有三个点，凑齐的很少：

1. **手机是主要目标，不是顺带兼容。** 大部分库内 agent 插件是桌面专属，因为它们本质是套一层 Claude Code、Codex 或本地 DSH 进程。这个插件从 Obsidian 内部直接发 HTTP，所以 iPhone 上不是残废版。
2. **一把 Key 干两件事。** 同一个 DeepSeek Key 负责语音转写、推理、联网搜索、读网页。不用第二个服务商，不用另买搜索额度。
3. **你没点头，它一个字都不写。** 读操作立即执行，写操作全部进队列等你按「执行这些操作」。这比「让 AI 自由编辑」笨，但你可以放心把库交给它。

### 明显不如别人的地方

- 模型便宜，长文细改能看出差距。遇到硬活，设置里切 `deepseek-v4-pro`。
- 中英两套界面都有，但英文文案是从中文原稿翻的，个别句子还带着中文的语序。
- 没有向量检索、没有语义搜索、没有带记忆的侧边栏。它是「帮你动手」的工具，不是「第二大脑」。

### 便宜在哪：缓存命中

DeepSeek 对命中缓存的输入按 **$0.003 / 百万 token** 计费，是未命中（$0.15）的五十分之一——但前提是请求**完整命中**一个缓存前缀单元。这直接决定了客户端该怎么写，这个插件是这么做的：

- 系统提示词和工具定义里永远不出现当前笔记名、时间、随机 id。会变的东西（打开了哪篇、队列里几条）放进用户消息，前面那一大段就能逐字节复用，换笔记、隔天再用都能命中。
- Agent 历史只追加不改写，「继续跑」复用同一份消息列表：一个 20 步的任务，第一轮付全价，后面十九轮按缓存价。
- 工具定义顺序固定，因为它也在前缀里。
- 正在改的笔记单独作为一条消息，你的指令放在它后面那条。同一篇连着改三次（先追加、再收紧、再补一句），从第二次起正文块就命中，因为变的只有结尾那段指令。
- Agent 模式里，同一次运行中第二次读同一篇，只返回一句「结果见上文」，不再把正文重复发一遍；工具结果回灌上限 9k 字，只砍中间、保留结尾——因为一次工具结果会在后面每一步被重发，长度要乘上步数。
- 每次回答下面显示「缓存 91% · 复用 8.2k + 新增 780 tok · 约 $0.0011 · 省 $0.0011」，效果看得见；设置页还有累计总数，可以清零。

实测大概是这样，不是承诺：

| 场景 | 输入里走缓存的比例 |
| --- | --- |
| 隔几小时后的第一次请求（或刚换模型 / 开关联网——这两样都会改掉前缀） | 0% |
| 单次短问答，前缀还热着 | 90–96% |
| 4–6 步的 Agent 任务 | 全部输入的 85–93% |
| 第一次改一篇没碰过的笔记（正文是新内容，任何缓存都不可能有） | 10–25%，也就是系统提示那一点 |
| 同一篇再改第二次 | 85–95% |

上限是结构性的：前缀只有系统提示 + 工具定义（约 2.4k token），后面的都是模型没见过的新内容。所以接近 100% 的命中率不存在，谁这么说，量的一定是别的东西。弹窗里显示每一次的真实数字，设置页记累计。

缓存被清掉后的第一次请求必然是未命中；官方是「尽力而为」，缓存保留几小时到几天。

但也得说清前提：以上按 Flash + 错峰算。你要是整篇长文反复改、切 `deepseek-v4-pro`、一次让它读十页网页，数字会翻好几倍。这里没有免费额度，也没有订阅——你充 DeepSeek，用多少扣多少，这也是它便宜的原因。

## 界面

弹窗的颜色全部取自你当前主题的变量，没有渐变、没有发光、没有浮在半空的圆角卡片配紫色强调——它看起来像 Obsidian 的一部分，而不是外挂的聊天框。一个强调色、一条细线、一档灰底，层次靠间距和字号做。深色浅色、以及各种社区主题都跟着变。

## 安装

### BRAT（推荐，iPhone 上唯一省事的路）

1. 社区插件里装 **BRAT**
2. BRAT → **Add Beta plugin** → 填 `raf-159357/deepseek-vault-agent`
3. 去「第三方插件」启用 **DeepSeek Vault Agent**

### 手动

从 [最新 Release](https://github.com/raf-159357/deepseek-vault-agent/releases/latest) 下载 `manifest.json`、`main.js`、`styles.css`，放进：

```
<你的库>/.obsidian/plugins/deepseek-vault-agent/
```

重开 Obsidian 启用即可。iPhone 的「文件」App 看不到 `.obsidian`，手机上请用 BRAT。

## 配置

1. 去 [platform.deepseek.com](https://platform.deepseek.com) → API keys 创建，充一点余额
2. Obsidian → 设置 → 第三方插件 → **DeepSeek Vault Agent** → 齿轮 → 粘贴 Key → 点 **测试连接**

默认值已经是对的：`https://api.deepseek.com`、模型 `deepseek-flash`、思考模式关闭（更快更省）。用中转站就改接口地址，带不带 `/v1` 都能识别。

## 手机上怎么用

iOS 不向第三方 App 开放音量键，从这几个入口里挑：

**悬浮按钮** —— 手机界面上浮一个圆钮：点一下进 AI 指令，长按进语音笔记，可以拖到不挡手的位置。设置里的「手机上的悬浮按钮」可以关掉。

**轻点背面** —— 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选你的快捷指令。快捷指令里只要一个动作「打开 URL」：

```
obsidian://vaultagent?mode=append
```

（旧的 `obsidian://deepvoice?...` 依然有效，而且会一直有效——你已经配好的快捷指令不用改。）

**桌面/锁屏小组件** —— 添加一个运行同一快捷指令的「快捷指令」小组件。

**移动端工具栏** —— 设置 → 移动端 → 管理工具栏 → 添加「语音输入：追加到当前笔记」。

弹窗里的顺序：**● 开始说话** → 说完再点一下 → 检查转写（同音字要改）→ **生成** → **写入笔记**。

想一步到位：链接里加 `&text=...&auto=1`，或者把设置里的「写入前需要确认」关掉。

## 命令与 URI

| 命令 | 用途 |
| --- | --- |
| 语音输入：追加到当前笔记 | 第一次先用这个 |
| 语音输入：改写当前笔记 | 整篇重排，保留 frontmatter |
| 语音输入：新建笔记 | 说完直接成文 |
| AI 指令：联网查资料 / 整理笔记 | 会搜、会读、会写 |
| AI 指令：读当前笔记里的链接并整理 | 批量读链接再汇总 |

```
obsidian://vaultagent?vault=<库名>&mode=append|rewrite|create-note&text=<编码后>&auto=1
obsidian://vaultagent?vault=<库名>&action=agent&text=<编码后>&auto=1
```

## 安全模型

- **读操作直接跑，写操作只排队。** AI 提议，你按「执行这些操作」才落盘。
- 路径校验：不许 `..`、不许绝对路径、不许碰 `.obsidian` 和隐藏目录。
- 限额：一次最多 12 个写操作、单篇最多 20 万字、一次最多 6 步（上限 12）。
- 删除默认关闭；开了也只进回收站，并且二次确认。
- 改写全文保留 YAML frontmatter；超过 800 KB 的笔记直接拒绝，不截断。

## 隐私与联网

插件只连一个地址：你在「接口地址」里填的那个（默认 `https://api.deepseek.com`）。

- 只有你在插件里录音时，音频才离开设备，且只发给语音接口。
- 只有你点「生成」或「发送」时，笔记内容才离开设备。
- 你没点确认，库就不会被改。
- 没有遥测、没有统计、没有账号、没有授权校验。
- Key 存在 `.obsidian/plugins/deepseek-vault-agent/data.json`。库若同步，Key 也会跟着同步——别把它放进公开库。

## 它做不到的事

- **不能后台定时跑。** 插件只在 Obsidian 打开时活着，iOS 不会按时唤醒它。要「每天早上 8 点」，用 iPhone 快捷指令的「个人自动化」去打开 URI。
- **读不了邮箱。** Gmail 要 OAuth 和原始 socket，Obsidian 的 WebView 两样都没有。变通：把邮件转发进一篇笔记（或转发给 email→RSS 服务），再跑「读当前笔记里的链接并整理」。
- **不流式输出。** 长任务表现为「停一会儿，然后一次性出结果」。
- **联网工具需要你的 DeepSeek 账号已开通。** 没开通会明确报错，不会瞎编。
